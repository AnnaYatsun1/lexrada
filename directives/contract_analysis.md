# Contract Analysis Directive

Извлеки из текста договора следующие данные:

## Стороны договора
Для каждой стороны найди:
- Наименование (полное, как подписано)
- Роль (Заказчик/Исполнитель/Покупатель/Продавец/итд)
- ИНН, ОГРН, КПП (если есть)
- Юридический адрес
- Подписант (ФИО)
- Должность подписанта
- Основание полномочий (устав/доверенность/приказ)
- Номер и дата доверенности (если применимо)
- Банковские реквизиты для платежей (если указаны)

## Существенные условия
- Номер и дата договора
- Предмет (что поставляется/выполняется)
- Цена (с указанием валюты, НДС)
- Порядок оплаты (авансе %, сроки)
- Сроки доставки/исполнения
- Штрафы и неустойки
- Порядок приёмки
- Условия расторжения
- Ответственность (ограниченная/неограниченная)
- Применимое право и подсудность

Верни JSON.
