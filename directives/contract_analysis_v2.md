# Contract Analysis Directive

Извлеки из текста договора структурированные данные.

## ПРАВИЛА ФОРМАТА (СТРОГО!)

- Даты: ТОЛЬКО формат YYYY-MM-DD (пример: 2025-02-12)
- Суммы в price: как написано в договоре (пример: "12 450 000 рублей без НДС")
- price_amount: ТОЛЬКО число без текста (пример: 12450000)
- currency: ТОЛЬКО код (RUB, USD, EUR)
- Если поле не указано в договоре — верни null. НЕ ПИШИ "не указано", "не определено", "отсутствует"
- Проценты: как в договоре (пример: "0,1% за каждый день просрочки")

## Стороны договора (parties)
Для каждой стороны:
- name: полное наименование как в договоре
- role: роль как указана (Заказчик/Исполнитель/Покупатель/Поставщик/Арендодатель/Хранитель/Агент/итд)
- inn: ИНН (только цифры) или null
- ogrn: ОГРН (только цифры) или null
- address: юридический адрес или null
- signatory_name: ФИО подписанта или null
- signatory_position: должность или null
- power_basis: "устав" / "доверенность" / "приказ" или null
- power_number: номер доверенности или null
- power_date: дата доверенности YYYY-MM-DD или null

## Существенные условия
- document_number: номер договора (без "№", без "Договор")
- document_date: дата заключения (YYYY-MM-DD)
- subject: предмет договора (кратко, 1 предложение)
- price: цена как в тексте
- price_amount: число
- currency: RUB/USD/EUR
- payment_terms: условия оплаты
- delivery_terms: условия поставки/передачи или null
- execution_term: срок исполнения
- penalties: штрафы/неустойки или null
- termination_terms: условия расторжения или null
- liability: ответственность или null
- acceptance_procedure: порядок приёмки или null
- governing_law: применимое право или null
- dispute_resolution: подсудность или null

Верни JSON строго по этой схеме.
